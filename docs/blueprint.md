# **App Name**: Nourishora Landing

## Core Features:

- Hero Section with CTA: Display a compelling hero section with headline, description, and a call-to-action button that scrolls to the waitlist form.
- About Section: Showcase an 'About' section with title, subtitle, main text, feature cards, and a CTA button to join the early access list.
- Benefits Section: Highlight the benefits of Nourishora with a title, subtitle, and benefit points with icons.
- Pilot Launch Areas: Display a grid of initial pilot launch locations with a note about future expansion.
- Waitlist Form: Implement a responsive form with fields for full name, preferred meal, address, phone number, and preferred delivery time.
- Google Sheets Integration: Connect the form to a Google Apps Script web app to save submitted data to a Google Sheet. Show success/error message on submission.
- Form Validation: Include Javascript to validate input on the client side before the form can be submitted to the server.

## Style Guidelines:

- Primary color: Seagreen (#2E8B57) for a fresh and healthy feel.
- Secondary color: Coral (#FF7F50) for a warm and appetizing accent.
- Background color: Light grey (#F9F9F9) to provide a clean backdrop.
- Headings: 'Poppins' (sans-serif, 600 weight) for a modern and clear header style.
- Body: 'PT Sans' (sans-serif, 400 weight) as a fallback for Open Sans (not supported by the tool) for a readable and clean body text.
- Use clean and minimalist icons that visually represent the benefits (fresh ingredients, balanced nutrition, etc.).
- Maintain a maximum width of 1200px. Implement a responsive layout with single-column stacking on mobile and multi-column layouts on desktop.
- Add a subtle loading animation or transition to provide feedback during form submission.
